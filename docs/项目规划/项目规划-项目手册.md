## 🗂️ 代码结构速查

```
src/main/java/com/example/navigation_menu/
│
├── controller/          MenuController.java        POST /api/menu/tree
│
├── service/
│   ├── impl/MenuServiceImpl.java           缓存检查 + Chain 编排（45 行）
│   │
│   ├── chain/                              ★ 责任链核心
│   │   ├── MenuHandler.java                Handler 接口
│   │   ├── MenuHandlerChain.java           链本体（@Order 排序 + 自动终止）
│   │   ├── MenuContext.java                贯穿整条链的数据公文包
│   │   └── handler/                        5 个 Handler
│   │       ├── LegacyCheckHandler.java     @Order(1)  查旧系统
│   │       ├── LoadMenuHandler.java        @Order(2)  拉菜单
│   │       ├── FallbackMatchHandler.java   @Order(3)  四维匹配
│   │       ├── PermissionFilterHandler.java @Order(4) 权限过滤
│   │       └── TreeBuildHandler.java       @Order(5)  O(n) 组树
│   │
│   ├── cache/MenuTreeCacheService.java    ★ Redis 缓存（get/put/evict）
│   ├── MenuFallbackService.java            四维通配匹配算法
│   ├── PermissionFilter.java               权限过滤
│   └── MenuTreeBuilder.java                O(n) HashMap 索引组树
│
├── mapper/              MenuConfigMapper + BranchConfigMapper
├── model/               entity / dto / vo
├── config/              RedisConfig（序列化）+ MybatisPlusConfig
└── exception/           BusinessException + GlobalExceptionHandler
```

## 🚀 快速验证

```powershell
# 启动（本仓库没有提交 Maven Wrapper，用本机的 mvn）
mvn spring-boot:run

# 第一次 curl（缓存 miss → 走责任链 → 存缓存）
curl.exe -s -X POST http://localhost:8080/api/menu/tree `
  -H "Content-Type: application/json" `
  -d '{"countryCode":"CN","entityCode":"RETAIL","channelCode":"APP","branchCode":"SH001","userId":"normal_user"}'

# 第二次 curl（缓存 hit → 直接返回，不走链）
# 控制台应该只有 cache hit 日志，没有 chain step 日志
```
